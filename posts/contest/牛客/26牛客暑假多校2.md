# 26牛客暑假多校2

## M

> 题目大意：有$n$个点，$m$条边，求连通但不相连点的对数，无自环或重边
> 数据范围：$1 \leqslant n \leqslant 10^5,\quad 0 \leqslant m \leqslant \min\left(10^9,\dfrac{n(n-1)}{2}\right)$
- $n \le 2$时，无论怎样都是0
- 当所有点连接成一条线的时候，取得最大值 当有$k$个点一条线，则有$\dfrac{(k-1)(k-2)}{2}$对点
- 当$m \le n-1$时 可以将$m+1$个点连成一条线，取得最大值$\dfrac{m(m-1)}{2}$
- 在$m=n-1$时取得最大值，当$m \ge n$时，每多一条边，最大值将减1，需要减去的部分为$m-(n-1)$多余出来边数
  
??? node "赛时代码"
```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

void fc() {
	ll n,m;std::cin>>n>>m;
    
    if(n<=2){
        std::cout<<0<<"\n";return;
    }
    
    if(m<=n-1){
        std::cout<<m*(m-1)/2<<"\n";
    }else{
        std::cout<<(n-1)*(n-2)/2-(m-(n-1))<<"\n";
    }
}

int main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int t = 1;
	std::cin>>t;
	while (t--) fc();
	return 0;
}
```

## N

> 题目大意 ：给定一个长度为n的数组，要求执行恰好一次，每次选取$k$个数，将$k$个数都变成这$k$个数都中位数，求这个数组最终和的最大值
> 数据范围：$1 \leqslant k \leqslant n,\quad \sum n \leqslant 2 \times 10^5,\quad 1 \leqslant a_i \leqslant 10^9$

- 由于排序不会影响答案，先排序
- 在**升序**条件下，要求操作后增量最大化，应当小于和大于中位数的部分都要最小，即假设$M$为中位数，前$x$个较小元素$(<=M)$无额外限制，直接取**全局最小**的$x$个，后$y$个较大元素$(>=M)$,最优解为紧跟中位数之后连续的$y$个
#### 1. $k$为奇数
- $m = \lfloor \frac{k-1}{2} \rfloor$，中位数 $M = b_m$
- 增量展开：
 $$\Delta = 2m \cdot b_m - \sum_{i=0}^{m-1} b_i - \sum_{i=m+1}^{2m} b_i$$

**贪心构造**：
- 1. 较小元素集合 ($b_0 \dots b_{m-1}$)：仅需满足 $b_i \le b_m$，无额外下界限制。要使和最小，直接选取全局最小的前 $m$ 个数，即排序后的前缀 $a_0, a_1, \dots, a_{m-1}$。
- 2. 较大元素集合 ($b_{m+1} \dots b_{2m}$)：必须满足 $b_i \ge b_m$。要使和最小，最优解为在排序数组中紧跟在 $b_m$ 后的连续 $m$ 个元素。

 **结构结论**：
- 1. 设 $b_m = a_j$（其中 $j \ge m$），则选取的 $k$ 个元素分割为：固定前缀：$a_0, a_1, \dots, a_{m-1}$（共 $m$ 个元素）。
- 2. 连续区间：$a_j, a_{j+1}, \dots, a_{j+m}$（共 $m+1$ 个元素，首元素为 $a_j$）。
- 
#### 2. $k$为偶数
- $d = \lfloor \frac{k-1}{2} \rfloor = m - 1$，中位数 $M = \frac{b_{m-1} + b_m}{2}$

- 增量展开：
 $$\Delta = (m - 1)(b_{m-1} + b_m) - \sum_{i=0}^{m-2} b_i - \sum_{i=m+1}^{2m-1} b_i$$
 
**贪心构造**：
- 1. 较小元素集合 ($b_0 \dots b_{m-2}$)：直接选取全局最小的前 $m-1$ 个数，即前缀 $a_0, a_1, \dots, a_{m-2}$。
- 2. 较大元素集合 ($b_{m+1} \dots b_{2m-1}$)：紧跟在中位数对 $(b_{m-1}, b_m)$ 后的连续 $m-1$ 个元素。
- 
**结构结论**：
    设 $b_{m-1} = a_j$（其中 $j \ge m-1$），则 $b_m = a_{j+1}$。选取的 $k$ 个元素分割为：
- 1. **固定前缀**：$a_0, a_1, \dots, a_{m-2}$（共 $d = m-1$ 个元素）。连续区间：$a_j, a_{j+1}, \dots, a_{j+m}$（共 $m+1$ 个元素，包含中位数对及其右侧元素）。
- 2. **连续区间**：$a_j, a_{j+1}, \dots, a_{j+m}$（共 $m+1$ 个元素，包含中位数对及其右侧元素）

#### 3.统一奇偶模型
> 为了方便计算，只需要统一变量无需大量奇偶讨论，通过滑动窗口求解

**固定前缀长度**：$d = \lfloor \frac{k-1}{2} \rfloor$

**连续窗口长度**：$L = k - d$

**滑动范围**：窗口首元素 $a_j$ 的下标 $j \in [d, n - L]$

```c++
#include <bits/stdc++.h>  
using namespace std;  
#define int long long
#define endl '\n'
const int mod = 1e9 + 7;
const int MOD = 998244353;


void ap() {
    int n,k;std::cin>>n>>k;
    std::vector<int>a(n);
    
    bool t=(k&1);
    int sk=k;
    
    int sum=0;
    for(int i=0;i<n;i++)std::cin>>a[i],sum+=a[i];
    std::sort(a.begin(),a.end());
    
    int d=(k-1)/2;
    int s=0,ans=LLONG_MIN;
    for(int i=0;i<d;i++)s+=a[i];
    k=k-d;
    
    for(int i=d;i<n;i++){
        s+=a[i];
        if(i<d+k-1)continue;
        
        int mid=(t?a[i-k+1]*sk:sk/2*(a[i-k+1]+a[i-k+2]));
        ans=max(ans,sum-s+mid);
        
        s-=a[i-k+1];
    }
    std::cout<<ans<<"\n";
}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int T = 1;
	cin >> T;
	while (T--) {
		ap();
	} 
    return 0;
}
```

#### 复制度
**时间复杂度**：排序 $\mathcal{O}(n \log n)$，滑动窗口维护 $\mathcal{O}(n)$，总时间复杂度 $\mathcal{O}(n \log n)$，完美通过 $\sum n \le 2 \times 10^5$。

**空间复杂度**：$\mathcal{O}(n)$ 存储数组，常数空间完成窗口滑动。
