# 并查集

## 简介

并查集(Disjoint Set Union)，主要解决的是元素分组类型的问题，能够高效管理不相交集合的数据结果，可以用几乎常数的时间处理集合合并和查询操作
* 合并(union)：把两个不相交的集合，合并成一个集合
* 查找(find)：找到当前节点所在的集合(当前集合的代表节点，树的根节点)，也可以通过查找判断两个节点是否属于同一集合

## 引入

???+ node "[luogu P1551 亲戚](https://www.luogu.com.cn/problem/P1551)"
    * **题目描述** 若某个家族人员过于庞大，要判断两个是否是亲戚，确实还很不容易，现在给出某个亲戚关系图，求任意给出的两个人是否具有亲戚关系
     
    * **规定** x 和 y 是亲戚，y 和 z 是亲戚，那么 x 和 z 也是亲戚。如果 x，y 是亲戚，那么 x 的亲戚都是 y 的亲戚，y 的亲戚也都是 x 的亲戚。
  
    * **输入格式** 第一行：三个整数 n,m,p，（n,m,p≤5000），分别表示有 n 个人，m 个亲戚关系，询问 p 对亲戚关系。
      以下 m 行：每行两个数 M_i，M_j，1≤M_i, M_j≤n，表示 M_i 和 M_j 具有亲戚关系。
      接下来 p 行：每行两个数 P_i,P_j，询问 P_i 和 P_j 是否具有亲戚关系。

    * **输出格式** p 行，每行一个 Yes 或 No。表示第 i 个询问的答案为 “具有” 或 “不具有” 亲戚关系。
  

我们把所有人都分到若干个集合中，一个集合的人就是具有亲戚关系，对每一个查询进行判断两个人是否是同一个集合，而要实现这种频繁的集合合并和查询，用链表，哈希表等时间复杂度是比较高的，而并查集能够支持高效的合并和查询操作，并查集最重要的一个核心思想就是用集合重点一个元素作为代表来表示这一个集合，也就是树的根节点
