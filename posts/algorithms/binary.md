# 二分
## 简介

二分的核心思想是在有序或者单调区间上通过折半排除，将线性时间复杂度**O(n)**优化为对数时间复杂度**O(logn)**. **唯一前提：单调性**

## 二分查找
### 定义

二分查找是通过在一个*有序*数组中查找指定元素的算法，时间复杂度为**O(logn)**(二分查找的最大优势),空间复杂度为**O(1)**(迭代实现),二分的查找有三种写法

### 引入

??? node "例题"
    给定一个长度为 $n$ 的非严格递增数组（满足 $a_i \le a_{i+1}$），以及一个查询目标值 $k$。
    请你求出数组中**第一个大于或等于 $k$ 的元素**所在的位置下标（下标从 0 开始计算）。
    如果数组中不存在大于或等于 $k$ 的元素（即所有元素都严格小于 $k$），则返回数组的长度 $n$。
???

### 过程

在这里描述*左开右开区间*(left,right) 
> 核心:(数组范围为0 ~ n-1)

> 搜索范围不包括left和right两个指针指向的元素 

> 初始值: left=-1，right=n (左右指针都指向数组边界外)

> 循环条件: left+1<right

#### 执行过程

以升序数组为例，假设我们要寻找第一个大于或等于 k 的元素（即 lower_bound 逻辑）。
每次比较中点 a[mid] 与 k 的大小：

* 如果 a[mid] >= k：说明目标边界要么是当前的 mid，要么在 mid 的左侧。为了逼近“最左侧”的极值，我们更新 r = mid。这保证了 r 及其右侧的元素始终满足 >= k。

* 如果 a[mid] < k：说明目标边界必定在 mid 的右侧，我们更新 l = mid。这保证了 l 及其左侧的元素始终满足 < k。
