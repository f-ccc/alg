## 执行计划

### 目标
在主页顶部导航栏的明暗切换按钮旁边添加一个 GitHub 图标链接，跳转到 `https://github.com/f-ccc/alg`。

### 方案
使用 VitePress 内置的 `socialLinks` 配置项，零额外代码实现。

### 改动文件
**仅一个文件：** `.vitepress/config.ts`

### 具体步骤

1. **删除** `nav` 数组中的文字 GitHub 链接：
   ```
   { text: 'GitHub', link: 'https://github.com/f-ccc/alg' },
   ```

2. **添加** `socialLinks` 到 `themeConfig` 中（放在 nav 数组下方或其他同级位置）：
   ```ts
   socialLinks: [
     { icon: 'github', link: 'https://github.com/f-ccc/alg' },
   ],
   ```

### 效果
- GitHub SVG 图标自动出现在导航栏右侧、明暗切换按钮左边
- 点击新窗口打开仓库
- 图标自动适配暗色/亮色模式
- 无需自定义 Vue 组件或 CSS
